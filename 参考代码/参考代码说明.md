# 参考代码目录

## 目录结构

```
参考代码/
├── 官方源码/              # DST 游戏官方源代码（从 scripts.zip 提取）
│   ├── components/         # 815 个游戏组件（核心！）
│   ├── prefabs/            # 1583 个预制体（物品、生物、建筑等）
│   ├── widgets/            # 183 个 UI 控件
│   ├── screens/            # 63 个游戏界面
│   └── 根目录核心脚本/     # 21 个核心脚本
│       ├── tuning.lua      # 游戏平衡常数（328KB）
│       ├── actions.lua     # 所有交互动作定义（269KB）
│       ├── recipes.lua     # 合成配方（196KB）
│       ├── standardcomponents.lua  # 标准组件注册（76KB）
│       ├── util.lua        # 通用工具函数（57KB）
│       └── ...更多...
│
└── 参考MOD/               # 放你想参考的其他 MOD 代码
    └── (空，等你放入)
```

## 使用方法

当你在制作 MOD 时需要参考某个游戏机制，**直接告诉我路径**即可，比如：

> "帮我看看 官方源码/components/container.lua 里容器是怎么实现堆叠的"
> "参考一下 官方源码/prefabs/chester.lua 的写法"
> "学习 官方源码/prefabs/cane.lua 手杖的实现方式"
> "看看 tuning.lua 里背包相关的平衡数值"
