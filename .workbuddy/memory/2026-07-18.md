#### 1. 过场动画（pocketwatch_warpback 状态图）
- **参考源码**：能力勋章 `scripts/components/medal_delivery.lua` 第 276 行
- **核心调用**：`player.sg:GoToState("pocketwatch_warpback", {warpback={dest_x=tx, dest_y=0, dest_z=tz}})`
- **原理**：`pocketwatch_warpback` 是 Wanda 怀表回溯动画状态（SGwilson.lua 第 20305 行）
  - `onenter`: 播放 `pocketwatch_warp` 动画 + 生成 `pocketwatch_warpback_fx` 特效

  - `pocketwatch_warpback_pst.onenter`: `SnapCamera()` + `ScreenFade(true, 0.5)` 渐显 + `Physics:Teleport`
- **客户端同步**：`SGwilson_client.lua` 的 `pocketwatch_warpback_pre` 状态有 `server_states = { "pocketwatch_warpback_pre", "pocketwatch_warpback" }`，自动同步
- **替换前**：`player.Physics:Teleport(tx, 0, tz)` → 直接传送，地图会跟着飞
- **替换后**：`player.sg:GoToState("pocketwatch_warpback", ...)` → 渐隐→传送→渐显

#### 2. 左键双击

- **注意**：左键单击会在地图放置标记（ping），双击会放两个，但标记几秒后消失且只对自己可见

- 改成左键双击后，左右键点击地图都完全没反应；用户误以为"设置的不是左键"（实际 button==1000 正确）

- `input.lua:179-184` `Input:OnMouseButton` 中 `self.onmousebutton:HandleEvent` 是无条件调用的 → 只要注册了，地图下左键事件一定会送达回调
- `constants.lua:394-395` `MOUSEBUTTON_LEFT=1000` / `MOUSEBUTTON_RIGHT=1001` → 代码 `button ~= 1000` 正确

### 修复
- 去掉 `ismastersim` 守卫（外层 `if not IsDedicated()` 已保证"有客户端才进"，专用服务器不会进来）

### 格子优化月眼传送过场修正（19:3）—— 弃用 pocketwatch_warpback
- 用户反馈：传送时有"复用的声音"和"很多特效"，但勋章时空符文看起来干净、无声音
- 排查结论：**pocketwatch_warpback 状态图本身是硬编码脏的**（SGwilson.lua）：
  - `onenter` `SpawnPrefab("pocketwatch_warpback_fx")` 怀表特效
  - `pocketwatch_warpback_pst.onenter` `SpawnPrefab("pocketwatch_warpbackout_fx")` 出口特效
  - `pocketwatch_warpback_pst` timeline `SoundEmitter:PlaySound("wanda2/characters/wanda/watch/recall")` **这就是"复用的声音"**，且每次传送必播
  - 渐隐 `ScreenFade` 仅在距离 >30 触发
- **勋章时空符文其实也用同一个状态图**（medal_delivery.lua:276 `GoToState("pocketwatch_warpback",...)`），所以它也有 wanda 特效+声音；用户觉得"干净"是因它是消耗品/近距离用完即毁、未留意
- 结论：pocketwatch_warpback **无法做到"只渐隐"**，渐隐/怀表特效/声音被绑死。不能用它做过场
- 最终方案（格子优化 modmain.lua ~889-957、~990-1002）：
  - 服务端 RPC 直接 `player.Physics:Teleport`，不再进状态图
  - 移除原 `talker:Say("󰀏 󰀯")` 多余冒字
  - 客户端双击时本地 `ThePlayer:ScreenFade(false, 0.4)` 黑屏（专用服务器也有效，屏幕效果是本地的）
  - 服务端 `SendModRPCToClient(MOD_RPC["hslot_mooneye"]["teleport_done"], player)` 通知客户端
  - 客户端 `AddClientModRPCHandler("hslot_mooneye","teleport_done", fn)` 收到后 `ThePlayer:ScreenFade(true, 0.4)` 渐显
  - 兜底：客户端黑屏后 `DoTaskInTime(0.6, ...)` 强制渐显，防网络延迟卡黑屏
- 注意：ScreenFade 对玩家自己调用在客户端有效（pocketwatch_warpback 客户端状态图也是对自己 ScreenFade），故专用服务器下黑屏正常
- 未改 modinfo（行为调整但属 bug 修正，不强制 bump；建议下次统一 bump）

### ⚠️ 勘误：ScreenFade 客户端为 nil（19:36 修复崩溃）

- **根因**：`ScreenFade` 是 `player_common.lua` 在 `master_postinit`（ismastersim）里才 `inst.ScreenFade = fns.ScreenFade` 绑定的服务端方法；客户端玩家实体 `ThePlayer` 没有该方法（client_postinit 未绑定）。它本质靠 set `player_classified.fadetime`/`isfadein` net var，由客户端 replica 监听到后自动全屏黑屏/渐显
