### 实现

#### 1. 过场动画（pocketwatch_warpback 状态图）
- **参考源码**：能力勋章 `scripts/components/medal_delivery.lua` 第 276 行
- **核心调用**：`player.sg:GoToState("pocketwatch_warpback", {warpback={dest_x=tx, dest_y=0, dest_z=tz}})`
- **原理**：`pocketwatch_warpback` 是 Wanda 怀表回溯动画状态（SGwilson.lua 第 20305 行）
  - `onenter`: 播放 `pocketwatch_warp` 动画 + 生成 `pocketwatch_warpback_fx` 特效
  - 4 帧后：距离 > 30 时 `ScreenFade(false, 0.5)` 渐隐
  - `animover`: 进入 `pocketwatch_warpback_pst`
  - `pocketwatch_warpback_pst.onenter`: `SnapCamera()` + `ScreenFade(true, 0.5)` 渐显 + `Physics:Teleport`
- **客户端同步**：`SGwilson_client.lua` 的 `pocketwatch_warpback_pre` 状态有 `server_states = { "pocketwatch_warpback_pre", "pocketwatch_warpback" }`，自动同步
- **替换前**：`player.Physics:Teleport(tx, 0, tz)` → 直接传送，地图会跟着飞
- **替换后**：`player.sg:GoToState("pocketwatch_warpback", ...)` → 渐隐→传送→渐显

#### 2. 左键双击
- **按钮常量**：左键 = `1000`，右键 = `1001`
- **双击检测**：两次左键抬起间隔 < 0.4 秒，位置差 < 20 像素（400 平方像素）
- **防拖拽**：鼠标按下→抬起移动 > 10 像素视为拖拽地图
- **注意**：左键单击会在地图放置标记（ping），双击会放两个，但标记几秒后消失且只对自己可见

#### 3. 玩家作为传送目标

- 排除自己（`ent ~= player`）和鬼魂（`playerghost` tag）

## 左键传送无反应 bug 修复（同日下午）

### 现象
- 改成左键双击后，左右键点击地图都完全没反应；用户误以为"设置的不是左键"（实际 button==1000 正确）

### 根因
- `AddPlayerPostInit` 里残留 `if TheWorld.ismastersim then return end` 守卫
- 非专用服务器（玩家自己开房）时 `TheWorld.ismastersim == true` → `AddMouseButtonHandler` 直接跳过注册 → 完全没反应
- 之前专用服务器客户端能用，是因为那边 ismastersim==false 能注册，bug 被掩盖

### 验证（确认 button 码与事件分发本身没问题）
- `input.lua:179-184` `Input:OnMouseButton` 中 `self.onmousebutton:HandleEvent` 是无条件调用的 → 只要注册了，地图下左键事件一定会送达回调
- `constants.lua:394-395` `MOUSEBUTTON_LEFT=1000` / `MOUSEBUTTON_RIGHT=1001` → 代码 `button ~= 1000` 正确

### 修复
- 去掉 `ismastersim` 守卫（外层 `if not IsDedicated()` 已保证"有客户端才进"，专用服务器不会进来）
- 放宽双击容错：拖拽阈值 10px→20px（100→400），双击窗口 0.4s/20px → 0.5s/40px（400→1600）

## 过场动画未触发（直接瞬移）bug 修复

### 现象
- 改成 `pocketwatch_warpback` 状态图后，地图传送仍然直接飞过去，没有任何过场动画

### 根因
- 判断语句写成 `if player.sg and player.sg.goToState then`，但 SG 组件方法名是 **`GoToState`（大写 G）**
- 小写 `goToState` 字段恒为 nil → 判断永远 false → 走 fallback 的 `player.Physics:Teleport` → 完全没动画

### 对比勋章
- 能力勋章 `medal_delivery.lua:276`：`deliverier.sg:GoToState("pocketwatch_warpback", {warpback={dest_x, dest_y, dest_z}})`（大写 G，正确）

### 修复
- 改为 `if player.sg and player.sg.GoToState then`

### 附加细节（SGwilson.lua）
- `pocketwatch_warpback` 状态只有 **传送距离 > 30（约 7~8 个地皮）** 才触发 `ScreenFade` 渐隐过场（第 20335 行）；近距离只播 warp 动画
- 参数：`data.warpback = { dest_x, dest_y, dest_z }`，onenter 读 `data.warpback`，在 `pocketwatch_warpback_pst.onenter`（第 20410 行）执行 Teleport
