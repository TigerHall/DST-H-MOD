## 水中木优化 - 修复 OceanTreeShadeRange nil 崩溃

**问题**：玩家反馈 `modmain.lua:36: attempt to compare number with nil`

**根因**：`GetModConfigData("OceanTreeShadeRange")` 在 modmain 顶层代码执行时返回了 `nil`。
DST 中 mod 配置加载存在异步时序问题，首次加载/更新后/配置损坏时 `GetModConfigData` 可能返回 nil 而非 modinfo 中定义的默认值。

**修复**：

- `modmain.lua` config 表 — 所有数值型配置加 `or 默认值` 兜底（`light_radius→0`、`shrink_scale→0`、`ovshrink_scale→0`、`fig_harvest_count→1`、`glommerfuel_period→0`、`glommer_sanityaura→0`、`OceanTreeShadeRange→22`）
- `modinfo.lua` — version 2.3 → 2.4
