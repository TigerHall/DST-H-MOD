# 2026-07-11

## HSLOT: 月眼地图揭示布景位置功能

根据用户需求，将橙/黄/紫色月眼的传送功能改为在地图上展示对应布景位置。

### 分析成果
- 研究了官方 `messagebottle` → `mapspotrevealer` → `player_classified.revealmapspot` 链路
- 研究了 static layout 源码（default_pigking, walledgarden, deciduous_pond, moonbaseone）
- 建立了月眼→布景→可搜索 prefab 的映射表

### 修改（第三次迭代 — 拓扑搜索 + 修正关键词）
- 核心：`RevealSetPieceLocation` 重写为双层搜索
  - `FindRoomByKeyword()`：`TheWorld.topology` 搜房间中心（官方 c_findroom 方式）
  - 搜索配置：`{ type="room", keyword="..." }` / `{ type="entity", prefab="..." }`
- 房间名修正：
  - 黄色洞窟：`Altar`（匹配 AltarRoom 圣地祭坛布景）——之前错写 pillar_atrium
  - 紫色洞穴 `entity:pillar_ruins`→`room:ToadstoolArena`（匹配 ToadstoolArenaMud/ToadstoolArenaCave，毒菌蟾蜍竞技场布景）
- `pillar_atrium` 有显式 AddTag→保留实体搜索为回退用，但主目标改为房间搜索

### 布景分层映射
| 月眼 | 地面 | 洞穴 |

| 🟣 紫 | statueglommer → pigking（格罗姆→猪王） | minotaur_spawner → pillar_ruins（迷宫→废墟） |

### 修改（最终 — 删除三个月眼传送回退 + ShowMap 居中修复）
- 删掉 yellow/orange/purplemooneye hook 中的 `GenericMoonEyeTeleport` 回退代码
- `moonrockcrater_teleport` 配置 + `GenericMoonEyeTeleport` 函数保留——moonrockcrater（带孔月岩）还在用
- 后续做地图点击传送时重新利用此配置项
- 客户端修复：劫持 `Controls:ShowMap`，当有 `world_position` 参数时，即使地图已打开也强制关闭重开，确保 `FocusMapOnWorldPosition` 跑一遍居中逻辑
- 持久化数据：纯 Lua `gmatch/match/tconcat` 序列化 `"uid=k1,k2|..."` → `TheSim:SetPersistentString` 实时写盘（每次揭示后立即保存，不依赖不可靠的 save 事件监听）
- 技能更新：在 dst-mod-dev 的 pitfalls.md（+5 条）、code-templates.md（+2）、mod-patterns.md、SKILL.md 中记录新知识

### 地图点击传送月眼（最终：MouseHandler + RPC 模式，完全复现参考MOD2）
- 完全放弃官方地图动作系统，改用社区 MOD 方式
- `TheInput:AddMouseButtonHandler` 劫持右键 → 双击检测（0.22s）→ 坐标转换（MOD2 的 `TheWorld.minimap.MiniMap:MapPosToWorldPos`）→ `SendModRPCToServer` → 服务端 `AddModRPCHandler` → `FindEntities({"mooneye"}, 30)` → `Physics:Teleport`
- 踩坑记录：坐标转换必须用 MOD2 的 minimap 方法（topscreen 三层转换不准确/不触发）；globalmapicon 搜不到（tag 同步不可靠）；直接右键不带双击会太灵敏
- `moonrockcrater_teleport` 配置：true 时地图传送 + 挖孔月岩传眼骨同时生效
- 额外传送目标：sentryward, moondial, townportal（加 mooneye tag）
- `AddModRPCHandler` 必须在全局注册，不能放在任何守卫内
- 坐标转换用 `TheWorld.minimap.MiniMap:MapPosToWorldPos`（参考MOD2方法）
- 检测单击 vs 拖拽：记录鼠标按下释放位置差，>10px = 拖拽
- 版本：3.1 → 3.2（modinfo 描述更新）
- 技能更新：pitfalls.md 19→26条，code-templates.md +模板13（地图点击传送MouseHandler+RPC）
