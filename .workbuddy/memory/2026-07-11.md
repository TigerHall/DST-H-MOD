## HSLOT: 月眼地图揭示布景位置功能

根据用户需求，将橙/黄/紫色月眼的传送功能改为在地图上展示对应布景位置。

### 分析成果
- 研究了官方 `messagebottle` → `mapspotrevealer` → `player_classified.revealmapspot` 链路
- 研究了 static layout 源码（default_pigking, walledgarden, deciduous_pond, moonbaseone）
- 建立了月眼→布景→可搜索 prefab 的映射表

### 修改（第三次迭代 — 拓扑搜索 + 修正关键词）
- 核心：`RevealSetPieceLocation` 重写为双层搜索
  - `FindRoomByKeyword()`：`TheWorld.topology` 搜房间中心（官方 c_findroom 方式）
  - 搜索配置：`{ type="room", keyword="..." }` / `{ type="entity", prefab="..." }`
- 房间名修正：
  - 黄色洞窟：`Altar`（匹配 AltarRoom 圣地祭坛布景）——之前错写 pillar_atrium
  - 紫色洞穴 `entity:pillar_ruins`→`room:ToadstoolArena`（匹配 ToadstoolArenaMud/ToadstoolArenaCave，毒菌蟾蜍竞技场布景）
- `pillar_atrium` 有显式 AddTag→保留实体搜索为回退用，但主目标改为房间搜索

### 修改文件

- `实验代码/modinfo.lua` — 新增 `backpack_viewer_enable` 开关，version 0.35→0.36

### 架构设计
- **物品**：复用 `reskin_tool` 动画/皮肤（equippable + spellcaster），右键目标触发探查
- **容器**：在目标实体上动态添加 `container` 组件，鱼箱贴图 `ui_fish_box_5x4`
- **展示方式**：SpawnPrefab 副本（带 `inspection_copy` + `nosteal` 标签），不修改原实体
- **只读保护**：`replica.container:EnableReadOnlyContainer(true)` + `itemtestfn` 双重只读（注意: 不可用 `container.readonlycontainer = true`，该方法已被 `makereadonly` 锁定）
- **清理机制**：监听 `onclose`（检查 opencount 防多人冲突）+ `onremove`（实体死亡自动清理）
- **兼容性**：副本有 `nosteal`，刷子狸偷窃/麋鹿鹅掉装备不影响
- **踩坑**：`readonlycontainer` 被 `makereadonly` 锁定，不能用 `= true` 赋值，必须通过 `replica.container:EnableReadOnlyContainer(bool)` 设置

### 跑马灯效果（追加）

- **实体层面**：`backpack_viewer.lua` 预制体服务端，`DoPeriodicTask(0.05)` 更新 `AnimState:SetAddColour` + 玩家手持 `SetSymbolMultColour/AddColour`
- **UI 层面**：`modmain.lua` 客户端，`AddClassPostConstruct("widgets/itemtile")` → `self.image:SetTint` 跑马灯
- **数值差异**（与手杖对比）：
  | 参数 | 手杖 | 探查器 |
  |------|------|--------|
  | COLOR_CYCLE_SPEED | 1.6s | 2.8s（更慢） |
  | BREATH_SPEED | 1.2s | 2.0s（更慢） |
  | BREATH_INTENSITY | 0.6 | 0.35（更柔和） |
- **始终开启**：背包探查器没有开关状态，跑马灯一直存在

### Phase 2 方案 B 删除（回到容器模式）

- 方案 B 自建 UI + RPC 代码已全部删除
- 自定义 Widget 代码保存至技能库：`~/.workbuddy/skills/dst-mod-dev/references/custom_ui_panel_ref.lua`
- 原因：Widget 坐标系统（root 为左下角原点 vs overlayroot 为中心原点）和交互（TheInput 坐标与 GetWorldPosition 不一致）调试成本高
- **关于全局物品池的想法**：类似 共享物品三维 mod 的思路——把物品存到 `TheWorld.components.inventory` 作为池，容器展示池中物品，操作回写 NPC。后续可以考虑实现，代替当前的"搬入搬出"模式。

### 共享池模式（最终方案-v2：副本实时同步）

NPC 物品**永不动**，池里放 SpawnPrefab 副本，操作实时同步：

| 操作 | 池发生 | 同步到 NPC |
|------|--------|-----------|
| 打开 | 创建副本放入池容器 | — |
| 玩家**拿走**副本 | `onitemlose` 事件 → 副本消失 | `inv:RemoveItem`/`Unequip` + `Remove()` 销毁原物 |
| 玩家**放入**物品 | 0.2s 轮询检测到真物品 | `container:RemoveItem` → `inv:GiveItem`/`Equip` |
| NPC 自己捡了东西 | 0.2s 轮询检测到新物品 | 补副本到池 |
| 关闭 | 移除剩余副本，销毁池 | — |

**NPC 物品全程不离开 NPC 身上**，只是池里有个对应的副本展示。
| NPC 捡了新东西 | `inventory` 有不在映射里的物品 | 创建新副本放入容器空位 |
| NPC 换装备 | `GetEquippedItem` 变了 | 旧副本移除 + 新副本创建 |

**容错**：所有 NPC 操作都包 `pcall`，任何一步炸了不崩游戏。

| 流程 | 说明 |
|------|------|
| **打开** | `Unequip` 全部装备到 slot 1-3；`GiveItem` 全部物品到 slot 4+ |
| **操作** | `itemtestfn` 完全放行（有 `inventoryitem` 就通过）；`readonly` = false |
| **关闭** | slot 1-3 匹配装备位→`Equip`；其余→`GiveItem` 回物品栏；满→`DropItem` |
| **过滤** | **无**——nosteal/bundle/container 全都显示和操作 || **PopulateInspectionContainer** | 不再 `SpawnPrefab` 副本，而是 `Unequip` + `GiveItem` 把目标身上的真实物品移入容器 |
| **CleanupInspection → ReturnItemsToTarget** | 关闭容器时遍历所有 slots，slot 1-3 尝试 `Equip` 回装备栏，其余 `GiveItem` 回物品栏，满则 `DropItem` |
| **itemtestfn** | slot 1-3 只接受对应 `equipslot` 类型的装备（参考 EQUIPSLOTS），slot 4+ 接受普通物品 |
| **EnableReadOnlyContainer(false)** | 放开只读，玩家可自由拖拽物品 |
| **nosteal 保护** | `is_inspectable()` 跳过 `nosteal`/`_container`/`bundle`/`irreplaceable` 标签的物品 |
| **兼容刷子狸** | 物品在容器期间调用 `Thief:StealItem` → 检查 `inventory`（空）→ 检查 `container` → 可以偷，但 `itemtestfn` 防 `nosteal` |
| **兼容吼叫掉装** | boss 吼叫调 `inventory:Unequip(HANDS)` → 装备在容器里不在 inventory → 无影响 |

## 实验代码：HeSeeSee（重写背包探查器）

用全新预制体 HeSeeSee 替换旧的 backpack_viewer，清理旧文件。

### 改动
- **预制体名**：`backpack_viewer` → `hesee_see`
- **旧文件清理**：删掉 `scripts/prefabs/backpack_viewer.lua`、`images/inventoryimages/backpack_viewer.{tex,xml}`
- **新文件**：
  - `scripts/hesee_see.lua` — 预制体定义，复用 `reskin_tool`（清洁扫把）动画
  - `images/inventoryimages/hesee_see.{tex,xml}` — 图标文件（原 backpack_viewer 改名）
- **modmain.lua 重写**：容器参数从 `backpack_viewer` 改为 `hesee_see`；使用真正的 NPC 物品搬入/搬出逻辑（旧代码打开空容器，新代码把 NPC 物品移入容器展示，关闭时归还）
- **modinfo.lua**：名称改为 `H-窥探仪`，v1.0

### 核心逻辑
- `useableitem` 右键触发 → `GetPlayerTarget()` 先找战斗目标，兜底搜 3 单位内实体
- `OpenNPCInventory()`：收集 NPC 的 `itemslots` + `equipslots` → `RemoveFromOwner` 卸下 → 放入容器（装备放 slot 16/17/18，物品放 1-15/19-20）→ `Open()`
- `onclosefn`：收集容器物品 → `RemoveItem` 清出 → 按 `_hss_equip_map` 还原（Equip/GiveItem）→ 删容器组件
- 超出 20 格的多余物品直接放回 NPC 物品栏（不进入容器）

### 视觉
- 鱼箱 5x4 布局 + slot16=手 17=头 18=身 装备背景
- 清洁扫把动画模型（reskin_tool）
- 合成配方：2 树枝，TECH.NONE

### 右键目标选择（v1.1 修正）
- 原方案：`GetPlayerTarget()` 搜索战斗目标/附近实体←用户指出不对
- 新方案：**劫持 `ACTIONS.INSPECT`**，通过 `AddActionHandler` 拦截。玩家装备 HeSeeSee 在手上，直接右键实体（原本是"检查"动作），服务端检查手上物品是 `hesee_see` 且目标有 `inventory` 组件，则打开容器代替检查文本
- 预制体路径修正：`scripts/hesee_see.lua` → `scripts/prefabs/hesee_see.lua`（DST 默认从 `scripts/prefabs/` 加载）
