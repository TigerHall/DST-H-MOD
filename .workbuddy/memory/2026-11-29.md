## 水中木优化 v2.6.2：护盾防护改为骨头盔甲 resistance 全免（物理+位面）
- 用户要护盾防护和 armorskeleton 一样（物理位面都不怕）。查源码发现：
  - 原 FULL_ABSORPTION 方案只挡物理；位面 spdamage 走 inventory:ApplyDamage 的另一条 SpDamageUtil 路径，armor 吸收率管不到。
  - armorskeleton 用 `resistance` 组件：命中后 inventory:ApplyDamage 直接 `return 0,nil`，物理+位面一起归零；`_combat` 标签匹配所有战斗攻击者（含位面）。
- 改动（modmain.lua SetupHatCombat）：
  - 去掉 armor:SetAbsorption(FULL_ABSORPTION)，改 `inst:AddComponent("resistance")` + `SetShouldResistFn` 用 forcefield tag 门禁；SHIELD_RESISTANCES 照抄 armorskeleton 七项。
  - 护盾视觉仍用 forcefieldfx + forcefield tag；DoTaskInTime 到期 ShieldEnd 移 tag/杀 fx/取消 task。
- ⚠️ 关键修正：resistance 全免时 combat 推 `blocked` 事件（带 attacker，**无 stimuli**）而非 attacked →
  - 反伤必须挂 blocked（已双监听 attacked+blocked 覆盖两种）。
  - stimuli 断链失效 → 改闭包共享 `local reflecting` flag 断链（防两玩家互殴无限递归崩服）。
- modinfo：version 2.6.1→2.6.2；hover 补"物理位面全免/bone-armor shield"。

## 水中木优化 v2.6.3：修复护盾防护不生效 + 换暗影盾特效 + 硬直免疫
- 实测反馈：反伤有，但防护没生效（仍掉 36/66 伤害），特效是铥矿皇冠 forcefieldfx。
- **根因**：§37b 只定义 SHIELD_RESISTANCES 表 + ShouldResistFn，漏了 `AddResistance(tag)` → tags 空 → HasResistance 永远 nil → 走 armor 36/66。
- 修复（modmain.lua SetupHatCombat）：
  - ShieldStart 逐个 `AddResistance`，ShieldEnd 逐个 `RemoveResistance`（★必须成对）。
  - ShouldResistFn 改用私有 `shield_active` 标志，不用 forcefield tag。
  - 特效 forcefieldfx → armorskeleton 的 `shadow_shield`(1~6)：照官方 PickShield(主盾3/6带1.2s冷却)，DoPeriodicTask(0.9) 周期刷新视觉；清理用 `fx:Remove()`（非 kill_fx）。
  - 反伤条件 HasTag("forcefield") → shield_active；shield_active 时受击闪一次盾反馈。
- **硬直免疫真相**（SGwilson 源码）：受击硬直只由 attacked 事件触发 GoToState("hit")；resistance 生效推 blocked 不推 attacked → 硬直自动免疫，armorskeleton 无额外代码。
- modinfo：2.6.2→2.6.3；hover 补"免疫受击硬直"。配平通过，未实机验证。
- verified-api-calls.md §37c 更正 + 三副本同步。
