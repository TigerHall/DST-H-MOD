## 二次修复：mod 加载崩溃（strict 报 AddAction 未声明）

- 报错 `variable 'AddAction' is not declared`：`GLOBAL.AddAction(MOONEYE_TELEPORT)` 与 `GLOBAL.AddPlayerPostInit(...)` 用了 `GLOBAL.` 前缀。

## 三次修复：传送完全不生效 + 需支持所有颜色月眼

- 根因：动作用了 `map_action=true` + `ACTIONS_MAP_REMAP`，但 `PlayerController:GetMapActions` 只把 `v.action.map_only` 的动作收进地图动作槽（`ba`），`map_action` 动作必须由普通右键动作经 `RemapMapAction` 触发，纯地图传送落空 → 动作被丢弃、点击无反应。
- 改为纯地图专属动作模式（照搬官方 `DIRECTCOURIER_MAP` / `SWAPBODIES_MAP`）：
  - 动作 `map_only=true, map_works_on_unexplored=true, closes_map=true`；
  - 新增 `MOONEYE_TELEPORT.maponly_checkvalidpos_fn(act)`：用 `act:GetActionPoint()` 取点击点 → `FindMoonEyeNear` 找月眼 → 返回 `(valid, reason, x, z, mapent)`；
  - `fn` 重新调用 `maponly_checkvalidpos_fn` 拿目标后 `Physics:Teleport` + 特效；
  - 删除不再需要的 `ACTIONS_MAP_REMAP` 块。
  - `pointspecialactionsfn` 仍返回 `{MOONEYE_TELEPORT}`（检测 `checkingmapactions` + 附近有月眼）。
- 所有颜色月眼：`mooneye.lua` 的 `buildeye` 对 yellow/orange/purple/green/red/blue 六种落地后都会自动 `SpawnPrefab("globalmapicon")` 并 `TrackEntity`，所以 `MAP_MOONEYE_PREFAWS` 扩成全部 6 色 + `moonrockcrater`（moonrockcrater 仍靠 maprevealable 出图标）。用户要求所有颜色都能传，已满足。
- version `2.2` → `2.3`（功能性修复，标记可用版本）。
- 同步修正项目记忆 MEMORY.md 的「地图点击传送」可复用模式：原来写成 `map_action`+`ACTIONS_MAP_REMAP`（错误），改为 `map_only`+`maponly_checkvalidpos_fn` 正确范式，并注明最初因 `map_action` 被丢弃的坑。

## 四次修复：右键仍无反应（客户端 `_target` 为 nil + 配置错挂）

- 现象：地图能看到月眼图标，但右键无反应、无「传送月眼」提示。
- 根因 1（致命）：`FindMoonEyeNear` 读 `icon._target` 取月眼实体。但 `globalmapicon` 是 `SetIsProxy(true)` 代理实体，`TrackEntity` 只在**服务端**执行（`mooneye.lua` 的 `init` 在 `ismastersim` 检查之后），客户端代理的 `_target` 恒为 nil（`common_server` 里 `inst._target = nil`）。而 `GetMapActions`/`pointspecialactionsfn`/`maponly_checkvalidpos_fn` 全跑在**客户端** → 永远匹配不上 → 无动作。
  - `DIRECTCOURIER_MAP` 能用，是因为它查 `ent.MiniMapEntity:EntityHasRestriction(...)`，根本不碰 `_target`。
- 根因 2（配置）：hook 原先只挂在 `config.moonrockcrater_teleport` 上；但各色月眼应由独立的 `colormooneye_toggle` 控制（config 表 line 15）。两者默认都 true 才侥幸装上。
- 修复：
  - 不再读 `_target`。改为给月眼实体本身 `AddTag("h_moon_eye_teleport")`（对所有 7 个 prefab 用 `AddPrefabPostInit`），`FindMoonEyeNear` 直接 `TheSim:FindEntities(pos, r, {"h_moon_eye_teleport"})` 搜实体本体（客户端/服务端通用，实体就在点击点位置）。
  - 配置解耦：`MOONEYE_TELEPORT_PREFAWS` 把每个 prefab 映射到其配置键（各色→`colormooneye_toggle`，crater→`moonrockcrater_teleport`），运行时生成 `ENABLED_MOONEYE`；hook 在 `next(ENABLED_MOONEYE) ~= nil` 时才装。
  - `moonrockcrater` 的 `maprevealable` 图标仍按 `moonrockcrater_teleport` 门控（line 699 不变）。
- 边界：远处/未加载的月眼实体在客户端未模拟，`FindEntities` 找不到——暂不覆盖（原 inspect 机制本就是近身触发，范围一致）。若需跨图传远处月眼，需改用 globalmapicon 代理位置（但 `GetIcon` 在 Lua 层未暴露，识别代理较脆，待定）。
- version `2.3` → `2.4`。
- 项目记忆 MEMORY.md：踩坑记录表新增 `globalmapicon 代理 _target 客户端为 nil` 行；地图点击传送小节修正「不能读 `_target`」并给出正确做法。
