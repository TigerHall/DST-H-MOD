# 2026-06-27 工作日志

## 手杖 UI 图标高亮系统

### 核心发现
- **实体 AnimState:SetMultColour 不影响 UI 图标** — ItemTile 用独立 Image widget 渲染
- Insight 正确做法：`self.image:SetTint()` 直接操作 ItemTile Widget
- `Text`/`Image` 在 modmain.lua 需 `GLOBAL.require("widgets/text")` 导入

### 踩坑记录
- `ChangeImageName` 不即时刷新 UI 图标，ItemTile 只在 RebuildLayout 重建，需移动物品才触发
- 皮肤贴图不能硬编码默认值，应从 `invitem.imagename` 动态读
- net_bool 事件驱动比 DoPeriodicTask 轮询更正统但更复杂

### 当前实现
- 服务端：`inst:AddTag/RemoveTag("caneon")` 同步开关状态
- 客户端：`AddClassPostConstruct("widgets/itemtile")` 对 cane ItemTile 做：
  - `self.image:SetTint(0.4, 1, 0.4, 1)` 图标着色
  - `Text(NUMBERFONT, 38)` 状态文字 "󰀏 开"/"󰀜 关"
  - `Image` 绿底光晕 + α 正弦波呼吸灯 (25fps)
- 状态检测：DoPeriodicTask(0.5) 轮询标签
- 配置项：`cane_icon_text`(默认开)、`cane_icon_glow_breath`(默认开)
- version: 3.6 → 3.8
