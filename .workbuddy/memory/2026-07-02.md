## 行走手杖优化 — UI 刷新从轮询改为快速卸装触发

**问题**：右键切换手杖状态后，客户端通过 `DoPeriodicTask(0.2)` 轮询 `HasTag("caneon")` 来刷新图标着色和文字，存在延迟和性能浪费。

**方案**：右键切换只在装备栏操作，状态切换后直接做一次 `Unequip + Equip` 快速循环，触发客户端 ItemTile 重建（天然读取当前标签状态），彻底干掉轮询。

**改动**（`行走手杖优化/modmain.lua`）：

1. **服务端 SetOnUseFn**（第782-793行）：状态切换 + UpdateAllFeatures 后，若手杖正在装备中，设置 `_quick_re_equip` 标志 → Unequip → Equip → 清除标志
2. **服务端 unequipped 事件**（第1815行）：守卫 `if inst._quick_re_equip then return end`，防止快速卸装触发状态重置（尤其是 `multi_tool_state_save=false` 时会 set `all_active=false`）
3. **客户端**（第2042-2051行）：移除 `DoPeriodicTask(0.2)` 轮询，保留初始 `UpdateCaneTileHighlight()`；`onremove` 中补充 `StopColorCycle()` 清理

**版本**：`modinfo.lua` version 3.9 → 4.0

## 行走手杖优化 — 简化触发 + 人物呼吸灯开关 + 默认配置调整

**改动**：

1. **简化快速卸装触发条件**：去掉 `config.enable_tool_toggle_icon or ... or ...` 判断，SetOnUseFn 是用户操作，直接触发即可
2. **新增 `enable_player_glow` 配置**（默认开启）：控制人物身上是否展示彩色呼吸灯效果。仅当 `enable_light_fx` 也开启时生效。关闭后手杖本身/swap_object 仍有呼吸灯，但人物身体 `SetAddColour` 不受影响
3. **默认配置调整**：`enable_razor`（剃刀）和 `enable_hoe`（锄头）默认改为 `false`

**版本**：`modinfo.lua` version 4.0 → 4.1
