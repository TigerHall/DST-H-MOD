# 2026-07-13

## 新 MOD 规划：离线玩家物品回收（hreturn）
- 需求：多人 DST，玩家离线 >游戏内10天，其物品生成箱子放在离开坐标；10天内重连原样带回。
- 方案：断线实时接管 + 保险库实体（不读存档文件，存档持久化交给 DST 自身）。
  - `hh_offlinevault`：inventory 组件托管物品 + OnSave/OnLoad(userid, leave_cycle, x, z)。
  - TheWorld "playerdeactivated" 拿物品 → vault；"playeractivated" <10天归还；WatchWorldState("cycles") 每日检测 >=10天 → 生成箱子。
- 官方参考（已查源码确认）：
  - `monkey.lua`/`powdermonkey.lua` 偷窃存物用的是猴子自身 `inventory` 组件（powder monkey `maxslots=20`），不是 container。
  - `thief` 组件只是 `DropItem` 到地上；海盗船 stash 才是 container（DST 地面无独立 stash prefab）。
  - 启示：临时保管用 inventory（同猴子），给玩家看的终态用 container（同箱子）。
- 确认决策：① 天数可配置(5/10/15/30 默认10)+总开关；② 终态用「巨大宝箱」container 4x4(16格) 复用官方 `ui_boat_ancient_4x4` 图集（base-game 资产，非 MOD 私有）+ 溢出多箱兜底，确保装得完。
- 已知坑：巨大宝箱需同时注册自定义 container widget 的 slotpos 网格，否则 UI 错位。
- 待办：搭 modmain.lua + hh_offlinevault.lua + hh_returnchest.lua(自定义 container widget) + modinfo 配置项(version+1)。

## hreturn MOD 已完成（离线物品回收 / H-Offline Return v1.0）
- 已生成文件：`离线物品回收/modinfo.lua`、`modmain.lua`、`scripts/prefabs/hh_offlinevault.lua`、`scripts/prefabs/hh_returnchest.lua`、modicon(tex/xml 复用格子优化)。
- 关键实现：
  - `hh_offlinevault`：隐藏网络实体 + `inventory` 组件(`maxslots=120`) 暂存离线玩家全部物品；OnSave/OnLoad 持久化 `userid`/`leave_cycle`（坐标靠 Transform 自带存档）。
  - `hh_returnchest`：4x4 巨大宝箱，复用官方 `ui_boat_ancient_4x4` 图集；itemtestfn 全收；外观用 `treasure_chest` 动画 + minimap `treasurechest.png`。
  - modmain：world 监听 `playerdeactivated`(接管→vault)/`playeractivated`(按 userid 归还并删 vault)/`WatchWorldState("cycles")`(每日检测 >= grace 天 → 生成箱子)；另加 world 加载后 2s 补查，覆盖服务器离线期间到期的情况。
  - 溢出兜底：`container:GiveItem(item,nil,nil,false)`（drop_on_fail=false 避免重复掉落），装不下则绕圈生成额外归还箱；极端残留丢脚下。
  - 调试命令 `c_listvaults()`（客户端）。
- 踩坑已规避：① inventory 无 `GetAllItems()`，手动遍历 `itemslots`+`equipslots` 快照；② 归还装备位用 `Equip` 而非 `GiveItem`（GiveItem 不自动装备）；③ `params.hh_returnchest` 注册写在 prefab 文件顶层，客户端/服务端都会执行（保证箱子 UI 网格生效）。
- 校验：三个 lua 文件用 luaparser 通过语法检查（无 Lua 运行时，改用 pure-python 解析）。
- 已更新 `setup-junctions.ps1` 添加 `"hreturn" = "离线物品回收"` 映射。
- 注意：`playerdeactivated` 时刻玩家实体仍持有物品（DST 断线不立即掉落），接管安全；宽限期内重连用新角色实体按 userid 匹配 vault。
