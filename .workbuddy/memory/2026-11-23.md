# 2026-11-23 工作日志

## hpack v1.7.1：背包自动采集优先存打开的六色月眼，兜底背包

需求（用户明确）：背包优化 mod 的自动采集改进适配格子优化 mod——有打开的蓝眼等六色月眼界面时，
优先把采集到的东西往月眼存；月眼装不下才回背包兜底。**触发条件不变**：仍要背包里有对应物品
且堆叠没满（targets 仍由背包未满堆叠生成）。

改动文件（背包优化/）：
- `modmain.lua` `collect_items_periodially`（原 237 行起）：
  - 加 `POCKET_KEYS = {hslot, purple_fish, orange_fish, yellow_fish, rabbitkinghorn, shadow}`
  - 加 `GetOpenedPocketContainer(player)`：官方 `TheWorld:GetPocketDimensionContainer(key)` +
    `container:IsOpenedBy(owner)` 找玩家打开着的月眼容器（世界单例，精确判查看者不串号）
  - 存放分支：月眼非空 + `CanAcceptCount(taken_item, take) >= take` → `pocket:GiveItem`；
    否则兜底 `container:GiveItem`（背包）。
  - 埋 `[hpack][pocketpick] --DIAG` log 2 处（打开哪个口袋 / 每物品存哪），验证后删。
- `modinfo.lua`：version `1.7`（两段式）→ **`1.7.1`**（按铁律补三段式第三段）；中英 description 补一句说明。

关键事实/坑（已回写技能 verified-api-calls.md 第 14 节，三副本 MD5 一致）：
- `GetPocketDimensionContainer` 是官方 world.lua:621 内建 API，跨 mod 不用 RPC/require，
  没装 hslot 时四色 key 返回 nil 自动跳过；绿 `rabbitkinghorn`/红 `shadow` 官方自带。
- `IsOpenedBy(player)` 官方 container.lua:727 = `openlist[player]`，世界单例容器判查看者可靠。
- ⚠️ **存放前必须 `CanAcceptCount(item, take) >= take` 预检**：`GiveItem` 满容器会
  `DropOverstackedExcess` + 把物品丢在容器位置（隐藏实体）＝丢东西。兜底回背包因 targets 由背包算必装得下。
- 设计：触发清单不受"优先存别处"影响，物品存月眼后自己容器仍没满→继续捡，自然收敛。

静态检查：lua_lint.py 两文件块配平过。待用户进游戏实测：打开月眼采集是否进月眼、月眼满是否回背包。
