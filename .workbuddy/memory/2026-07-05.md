# 2026-07-05 工作日志

## 耕作帽夜视+防风暴功能（仿复眼勋章机制）

### 分析

调查了能力勋章 1909182187 中复眼勋章 (ommateum_certificate) 的三个核心机制：

1. **夜视能力**: `playervision:PushForcedNightVision(source, priority, colourcubes, blend)`
   - 需要自定义 colourcubes 表（day/dusk/night/full_moon）
   - 本源增强后改用 identity_colourcube → 无彩色滤镜

2. **防风暴效果**: `playervision:ForceGoggleVision(true)`
   - 强制启用护目镜状态，游戏过滤沙尘暴视觉效果
   - 本源增强后: hook `widgets/gogglesover.ToggleGoggles` → show=false 隐藏滤镜

3. **0% 耐久烧血特效**:
   - Service side: `net_bool("ismedallosehealth")` 同步 → 每秒扣血（逐次递增）
   - Client side: `widgets/itemtile` + `UIAnim("inventory_fx_acidsizzle")` 红色酸蚀动画
